# 카카오톡 업데이트 대응

검증 기준은 macOS 카카오톡 26.9입니다. DB 스키마·AX 식별자·URL 스킴·입력 동작은 업데이트로 달라질 수 있습니다. 기존 분석은 [docs/re](re/2026-11-03-kakaotalk-26.9.md), 공개 동작 계약은 [README](../README.md), API는 [라이브러리 가이드](library.md)를 기준으로 확인합니다.

## 1. 현재 환경 진단

업데이트한 카카오톡에 본인 계정으로 로그인한 상태에서 실제 운영 실행 주체로 실행합니다.

```sh
kkt doctor
kkt doctor --json
```

앱의 정확한 버전(`CFBundleShortVersionString`), macOS 버전, 실행 주체와 권한, 각 `warn`/`fail`을 기록합니다. 터미널과 데몬의 권한 주체는 다를 수 있습니다. 미검증 버전의 `warn`을 지우기 위해 먼저 버전 목록에 추가하지 마세요.

`doctor`는 현재 표시된 화면만 검사합니다. 메인 창·채팅 탭을 표시하고 다시 확인하되, 숨겨진 검색칸·채팅 창·프로필 카드·공지 상세의 호환성은 별도로 점검합니다.

## 2. AX 기준표 비교와 재측정

1. [기존 분석 3절의 AX 식별자 기준표](re/2026-11-03-kakaotalk-26.9.md#3-ax-식별자-기준표-269)와 현재 화면을 비교합니다.
2. Accessibility Inspector 또는 AX 덤프 도구로 각 화면의 `AXRole`, `AXIdentifier`, `AXTitle`, `AXDescription`, `AXValue`, 지원 동작과 부모·자식 경로를 재측정합니다. `kkt`에는 AX 전체 덤프 명령이 없으므로 외부 도구를 사용합니다.
3. 메인 창, 채팅 목록 행, 검색 버튼·검색칸·지우기 버튼, 채팅 입력칸·전송 버튼, 잠금 안내, 참여 화면, 프로필 카드, 공지 배너·상세 본문을 확인합니다. 검색칸 표시 전후와 라이트·다크 모드 차이도 기록합니다.
4. 공지 본문은 DB 길이와 화면 전문을 UTF-16 단위로 비교합니다. 공지 댓글 입력칸·등록 버튼은 조작하지 않습니다. 프로필 카드의 AX 노출 여부와 OCR 경로도 재확인합니다.
5. 덤프·스크린샷·DB 예시에서 사용자 ID, 방·사용자 이름, 채팅·링크 ID, 참여 코드, 본문, 기기 UUID, 로컬 절대 경로를 제거한 뒤 기록합니다. DB 키·인증정보는 수집하거나 게시하지 않습니다.

사용자가 연 창을 닫거나 기존 입력을 덮어쓰지 않도록 별도 검증 순서를 정합니다. 글·사진 전송 검증이 필요하면 본인 나와의 채팅 등 명시적으로 선택한 대상에서만 수행하고, 실측 여부와 단위테스트 결과를 구분합니다.

## 3. 상수와 호환성 수정

측정 결과를 바탕으로 `Sources/KktCore/Support/KktConstants.swift`와 각 모듈의 `KktConstants` 확장을 갱신합니다. AX 기준은 `Doctor/AXIdentifierTable.swift`, 공지 기준은 `Notice/NoticeReader.swift`·`Notice/NoticeAX.swift`에도 있으므로 함께 비교합니다. 식별자뿐 아니라 role·계층·버튼 의미가 같은지 확인하세요. 상수 교체로 해결되지 않는 흐름 변화는 해당 모듈에서 원인을 고칩니다.

개인정보를 제거한 픽스처로 회귀 동작을 검증합니다. 큰 ID는 2^53을 초과하는 가상 `Int64`를 유지하고, `Int64.max`인 미전송 메시지 경계도 보존합니다. 기존 테스트 기대값을 새 오동작에 맞추지 마세요.

```sh
CLANG_MODULE_CACHE_PATH=/tmp/kkt-clang-module-cache swift test --build-system native --disable-sandbox
```

백그라운드 입력, 한글 IME 전면 사용 거절, 사용자 창 거절, 검색 텍스트·클립보드·포커스 복원, 전송 확인, 공지 화면 경로를 확인합니다. 테스트만 통과했다면 실제 앱에서 검증했다고 기록하지 않습니다.

## 4. 검증 버전 등록과 기록

검증을 마친 뒤 `~/.config/kkt/config.json`의 기존 항목을 유지하면서 **앱이 보고한 정확한 버전 문자열**을 `verifiedKakaoVersions`에 추가합니다. 예를 들어 `26.9.0`과 `26.9`는 다른 문자열입니다. 이 목록은 사용자 설정이며 앱 호환성을 자동으로 판정하거나 허용하는 장치가 아닙니다.

새 분석 파일 `docs/re/<date>-kakaotalk-<version>.md`를 추가합니다. `<date>`는 `YYYY-MM-DD`, `<version>`은 측정한 버전으로 바꾸고 다음을 포함합니다.

- 검증 날짜, macOS·카카오톡 버전과 실행 주체
- 이전 버전 대비 DB·AX·URL 스킴 변화 및 AX 식별자 표
- 개인정보를 제거한 재현 절차·덤프 발췌와 변경한 상수
- 자동 테스트 결과, 실제 앱에서 확인한 동작, 미확인 항목과 남은 제한

마지막으로 같은 실행 주체에서 `kkt doctor`를 다시 실행하고 새 기록과 README의 검증 버전·제한 안내를 맞춥니다. 예전 분석은 당시 관찰 기록으로 보존합니다.
